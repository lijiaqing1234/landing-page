The **Smart Campus Activity Management System** is a full-stack platform I
developed to streamline campus activities and student services. It connects
students, organization leaders, and administrators through role-specific
workflows for activity registration, organization management, check-in,
assessment-score review, resource applications, notifications, and feedback.

The backend is built with **Java 17, Spring Boot, and MySQL**, while the
frontend uses **Vue 3, Pinia, Element Plus, and Vite**. The system also includes
an optional AI assistant that answers campus-related questions using contextual
information about activities, organizations, registrations, and scores.

[View the project on GitHub](https://github.com/Pengfei-Yang01/smart_campus_system)
